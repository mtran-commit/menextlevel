Shop page purpose

Display Me Next Level physical kits for sale.

Each kit card must show:

Product image
Kit name
Short description
Price
ORDER NOW button
Layout

Keep the Me Next Level visual identity:

black background
white text
premium warm-gold accents
clean product photography
subtle borders
minimal design

Desktop:

show products in a 2–3 column responsive grid.

Mobile:

show one product card per row.

Product detail should support:

larger product images
full description
what's included
price
quantity
Order Now / Buy Now
